# Uni-Ark

[Play Uni-Ark](https://jamesfdickinson.github.io/uni-ark/)

The flood is coming, and the water is rising fast. One unicorn is determined to reach Noah's Ark. Guide it through a dangerous maze, avoid obstacles, collect power-ups, and find the fastest route to safety. The ark is waiting. Probably.

## Controls

WASD, arrow keys, or swipe.

## Features

Built with vanilla JavaScript and HTML Canvas, with procedural graphics, sound effects, multiple endings, achievements, and a hidden second quest, maybe.
